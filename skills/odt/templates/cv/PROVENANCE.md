# Provenance: cv

- **Source**: hand-curated for `open-document-skills`
- **Author**: open-document-skills contributors
- **License**: MIT (see `LICENSE.txt`)
- **Design language**: compact academic CV layout, Lato single-font, navy
  section headers with bottom-rule (`#1B3A57`). A4 with 2 cm margins
  (CV-typical). Footer carries `[Name] · Page N`. Section structure follows
  the European academic convention.
- **Intended use**: applications to universities, fellowships, postdocs,
  third-party-funded positions. Disciplinary variation handled by which
  sections the user includes, not by the template.
