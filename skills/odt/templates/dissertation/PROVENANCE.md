# Provenance: dissertation

- **Source**: hand-curated for `open-document-skills`
- **Author**: open-document-skills contributors
- **License**: MIT (see `LICENSE.txt`)
- **Design language**: long-form thesis/Habilitation layout. A4 with 3 cm
  margins (DIN standard for dissertations), Lato chapter/section
  headings, Source Serif body at 1.4 line-height (comfortable for long
  reads). Chapters break to a new page (Heading1 has
  `fo:break-before="page"`). 5-level outline numbering. Hanging-indent
  bibliography style. Title-page styles include `Title`/`Subtitle`/`Dedication`.
- **Intended use**: PhD dissertations, Habilitationen, and any long-form
  scholarly monograph. Pairs deeply with v1.10 indexes
  (TOC + bibliography + figure index + alphabetical index).
